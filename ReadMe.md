# Samba

## General

[Samba](https://github.com/aniondev/Samba) is a docker-image for running a [Samba](https://www.samba.org)-server in a docker-container.
It is based on [dperson/samba](https://github.com/dperson/samba).
The available configuration-options are documented in [Samba/ReadMe.md](https://github.com/aniondev/Samba/blob/main/Samba/ReadMe.md).
