# Release notes

## Changes

- Pinned the version of the installed apk-package `samba` (`Samba/Other/Resources/Dependencies/Samba/Version.txt`, currently `4.22.10-r0`), which is passed to the Dockerfile as build-argument `SambaVersion`.
- Added `Samba/Other/UpdateDependencies.py`, which updates this pinned version to the version which the used alpine-image provides.
