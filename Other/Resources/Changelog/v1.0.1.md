# Release notes

## Changes

- Refactored the repository-structure so that it implements the common project structure.
- Updated the dependencies: the base-image is now pinned explicitly (`docker.io/library/alpine:3.23.4`, managed in `.ScriptCollection/OCIImages/ImageDefinition.csv`).
- The image is now built for `linux/amd64` and `linux/arm64` by the build-pipeline; the separate Dockerfiles and Docker-Hub-hooks for `aarch64` and `armhf` were removed.
