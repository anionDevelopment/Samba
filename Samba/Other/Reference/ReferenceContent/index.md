# Samba reference

Samba is a docker-image for running a Samba-server in a docker-container.

The configuration-options (command-line-arguments and environment-variables) are documented in [Samba/ReadMe.md](https://github.com/anionDevelopment/Samba/blob/main/Samba/ReadMe.md).

The following examples are available:

- [Minimal docker-compose-file](https://github.com/anionDevelopment/Samba/blob/main/Samba/Other/Reference/ReferenceContent/Examples/MinimalDockerComposeFile/docker-compose.yml)
- [Avahi-service-file for Time Machine](https://github.com/anionDevelopment/Samba/blob/main/Samba/Other/Reference/ReferenceContent/Examples/TimeMachineAvahiService/_etc_avahi_services_samba.service)
